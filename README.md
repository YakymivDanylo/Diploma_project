# Децентралізована система верифікації документів на основі власної реалізації блокчейн-технології

> Дипломна робота

## Актуальність

Підробка дипломів, сертифікатів та інших офіційних документів залишається поширеною проблемою, а традиційна верифікація (запити до установи, що видала документ) є повільною та незручною. Блокчейн дозволяє створити прозорий, незмінний реєстр, де автентичність документа перевіряється миттєво без посередників.

## Мета роботи

Розробити та дослідити спрощену блокчейн-систему для видачі та верифікації цифрових документів, включно з реалізацією та порівняльним аналізом алгоритмів консенсусу.

## Завдання

1. Дослідити принципи побудови блокчейн-систем та існуючі рішення (Blockcerts та ін.)
2. Реалізувати власний блокчейн на Python (структура блоків, хешування SHA-256, ланцюжок цілісності)
3. Реалізувати та порівняти алгоритми консенсусу (наприклад, Proof of Work та PBFT) за швидкістю, стійкістю до атак
4. Розробити веб-інтерфейс на React для видачі документів, їх верифікації за хешем та візуалізації блокчейну
5. Провести тестування системи на стійкість до типових атак (Sybil-атака, підробка задніх записів)

## Технологічний стек

| Шар | Технології |
|---|---|
| Backend / блокчейн-вузол | Python, FastAPI, asyncio |
| Мережева взаємодія вузлів | REST, WebSocket |

| Криптографічні підписи | ECDSA/RSA (бібліотека `cryptography`) |
| Frontend | React |

| Децентралізоване зберігання документів (опційно) | IPFS |
